## Reporting a Vulnerability
  
How to report a vulnerability: 
Please use the "Private Vulnerability Reporting" option for this Repo (check under the Security tab), or PM me via GitHub.  
Within 2 weeks, I'll review and either implement a fix, or offer insight for any delays or hesitations.  
In case I not respond within 2 weeks, it is encouraged to add an Issue and/or Pull Request to share the concern.
